# OntoDemer

## Related data and artifacts

Public, non-identifying data and ontology artifacts associated with the Demerzel study are available in Zenodo:

- DOI: [10.5281/zenodo.22037485](https://doi.org/10.5281/zenodo.22037485)
- Demerzel repository: [impisa88/Demerzel](https://github.com/impisa88/Demerzel)

This repository contains the OntoDemer ontology and its SPARQL query examples.
